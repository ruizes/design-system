# 设计令牌系统与数据模型

## 1. 概述

本项目虽然是纯前端展示项目，没有传统的后端数据库，但通过**设计令牌系统**和**组件数据模型**构建了完整的前端数据架构。本文档将详细介绍：

- 设计令牌系统（Design Tokens）
- 组件数据模型
- 未来数据库扩展方案

## 2. 设计令牌系统

### 2.1 什么是设计令牌

设计令牌是设计系统的基础构建块，是存储视觉设计决策的变量。它们替代了硬编码的值（如颜色、字体、间距），确保跨产品的一致性和可扩展性。

### 2.2 设计令牌的优势

| 优势 | 说明 |
|------|------|
| 一致性 | 确保所有产品使用相同的视觉规范 |
| 可维护性 | 一处修改，全局生效 |
| 可扩展性 | 轻松支持主题切换、多品牌等 |
| 协作性 | 设计和开发使用相同的语言 |

| 令牌名称 | 值 | 相对大小 | 典型用途 |
|----------|-----|----------|----------|
| `--space-xs` | 0.25rem (4px) | 极小 | 紧凑元素间距 |
| `--space-sm` | 0.5rem (8px) | 小 | 小元素间距 |

**间距使用原则**：
- 使用固定的间距令牌，避免随机像素值
- 保持间距的一致性和节奏感
- 响应式设计中可调整间距大小

| 令牌名称 | 值 | 典型用途 |

| `--shadow` | 0 1px 3px 0 rgba(0, 0, 0, 0.1), 0 1px 2px 0 rgba(0, 0, 0, 0.06) | 默认阴影 |

**阴影层级原则**：
- 层级越少越好，保持视觉简洁
- 悬停状态使用更大阴影
- 模态框使用最大阴影

### 2.4 设计令牌的使用

#### 2.4.1 CSS 中使用

```css
/* 直接使用令牌 */
.button {
    background: var(--primary);
    padding: var(--space-md) var(--space-xl);
    border-radius: var(--radius-md);
    transition: var(--transition);
}

/* 结合使用 */
.card {
    background: white;
    box-shadow: var(--shadow);
    padding: var(--space-xl);
    border-radius: var(--radius-lg);
```

```css
[data-theme="dark"] {
    --primary: #60a5fa;
    --bg-color: #111827;
    --text-color: #f3f4f6;

/* 使用 */
body {
    background: var(--bg-color);
    color: var(--text-color);
}
```

## 3. 组件数据模型

本项目中的数据以**硬编码形式**存在于组件中，主要包括：
- 产品数据
- 团队成员数据
- 页面内容数据

虽然目前是静态数据，但设计了清晰的数据结构，为未来接入数据库做好了准备。

## 4. 未来数据库扩展方案

### 4.1 数据库选型建议

根据项目特性，推荐以下数据库方案：

| 场景 | 推荐方案 | 理由 |
|------|----------|------|
| 小型项目/原型 | SQLite | 零配置、文件存储、适合快速开发 |
| 中型项目 | PostgreSQL | 功能强大、支持JSON、开源免费 |
| 大型项目 | PostgreSQL + Redis | 主数据库 + 缓存层，高性能 |
| 实时数据 | Firebase / Supabase | 实时同步、认证集成 |

### 4.2 推荐数据库架构

#### 4.2.1 核心表设计

```sql
-- ============================================
-- 设计系统数据库架构 (PostgreSQL)
-- ============================================

-- 1. 产品表
CREATE TABLE products (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    slug VARCHAR(255) UNIQUE NOT NULL,
    description TEXT,
    price DECIMAL(10, 2) NOT NULL DEFAULT 0,
    original_price DECIMAL(10, 2),
    category_id INTEGER REFERENCES categories(id),
    icon VARCHAR(255),
    image_url VARCHAR(255),
    status VARCHAR(20) DEFAULT 'active', -- active, inactive, draft
    sort_order INTEGER DEFAULT 0,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 2. 产品分类表
CREATE TABLE categories (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    slug VARCHAR(100) UNIQUE NOT NULL,
    description TEXT,
    icon VARCHAR(255),
    sort_order INTEGER DEFAULT 0,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 3. 团队成员表
CREATE TABLE team_members (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    role VARCHAR(100) NOT NULL,
    avatar_url VARCHAR(255),
    bio TEXT,
    email VARCHAR(255),
    social_links JSONB DEFAULT '{}', -- { github: "", twitter: "" }
    sort_order INTEGER DEFAULT 0,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 4. 页面配置表 (用于 CMS)
CREATE TABLE page_configs (
    id SERIAL PRIMARY KEY,
    page_key VARCHAR(100) UNIQUE NOT NULL, -- home, products, about 等
    title VARCHAR(255),
    meta_description TEXT,
    content JSONB DEFAULT '{}', -- 页面动态内容
    is_published BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 5. 特性卡片表
CREATE TABLE feature_cards (
    id SERIAL PRIMARY KEY,
    page_config_id INTEGER REFERENCES page_configs(id),
    icon VARCHAR(255),
    title VARCHAR(255) NOT NULL,
    description TEXT,
    animation_delay VARCHAR(20),
    sort_order INTEGER DEFAULT 0,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 6. 统计数据表
CREATE TABLE stat_cards (
    id SERIAL PRIMARY KEY,
    page_config_id INTEGER REFERENCES page_configs(id),
    value VARCHAR(50) NOT NULL,
    label VARCHAR(100) NOT NULL,
    sort_order INTEGER DEFAULT 0,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 7. 联系信息表
CREATE TABLE contact_info (
    id SERIAL PRIMARY KEY,
    icon VARCHAR(50),
    label VARCHAR(100) NOT NULL,
    value VARCHAR(255) NOT NULL,
    link_url VARCHAR(255),
    sort_order INTEGER DEFAULT 0,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 8. 导航菜单表
CREATE TABLE nav_items (
    id SERIAL PRIMARY KEY,
    parent_id INTEGER REFERENCES nav_items(id),
    label VARCHAR(100) NOT NULL,
    path VARCHAR(255),
    icon VARCHAR(50),
    sort_order INTEGER DEFAULT 0,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
```

### 4.3 API 层设计

#### 4.3.1 RESTful API 规范

| 资源 | 方法 | 端点 | 描述 |
|------|------|------|------|
| 产品 | GET | `/api/products` | 获取产品列表 |
| 产品 | GET | `/api/products/:id` | 获取单个产品 |
| 产品 | POST | `/api/products` | 创建产品（管理员） |
| 产品 | PUT | `/api/products/:id` | 更新产品（管理员） |
| 产品 | DELETE | `/api/products/:id` | 删除产品（管理员） |
| 团队成员 | GET | `/api/team` | 获取团队列表 |
| 页面配置 | GET | `/api/pages/:key` | 获取页面配置 |
| 联系信息 | GET | `/api/contact` | 获取联系信息 |

#### 4.3.2 API 响应格式

```typescript
    };

// 错误响应
interface ApiError {
    success: boolean;
    error: {

    };
}
```

```javascript
// routes/products.js
import express from 'express';
import { db } from '../config/database.js';

const router = express.Router();

// 获取产品列表
router.get('/', async (req, res, next) => {
    try {
        const { page = 1, pageSize = 10, category } = req.query;
        const offset = (page - 1) * pageSize;
        
        let query = `
            SELECT p.*, c.name as category_name 
            FROM products p
            LEFT JOIN categories c ON p.category_id = c.id
            WHERE p.status = 'active'
        `;
        const params = [];
        
        if (category) {
            query += ' AND c.slug = ?';
            params.push(category);
        }
        
        query += ' ORDER BY p.sort_order ASC, p.id DESC';
        query += ' LIMIT ? OFFSET ?';
        params.push(parseInt(pageSize), offset);
        
        const products = await db.all(query, params);
        
        // 获取总数
        let countQuery = 'SELECT COUNT(*) as total FROM products WHERE status = "active"';
        const countParams = [];
        
        if (category) {
            countQuery += ' AND category_id = (SELECT id FROM categories WHERE slug = ?)';
            countParams.push(category);
        }
        
        const { total } = await db.get(countQuery, countParams);
        
        res.json({
            success: true,
            data: products,
            pagination: {
                page: parseInt(page),
                pageSize: parseInt(pageSize),
                total,
                totalPages: Math.ceil(total / pageSize)
            }
        });
    } catch (error) {
        next(error);
    }
});

// 获取单个产品
router.get('/:id', async (req, res, next) => {
    try {
        const product = await db.get(`
            SELECT p.*, c.name as category_name 
            FROM products p
            LEFT JOIN categories c ON p.category_id = c.id
            WHERE p.id = ? AND p.status = 'active'
        `, [req.params.id]);
        
        if (!product) {
            return res.status(404).json({
                success: false,
                error: {
                    code: 'NOT_FOUND',
                    message: '产品不存在'
                }
            });
        }
        
        res.json({
            success: true,
            data: product
        });
    } catch (error) {
        next(error);
    }
});

export default router;
```

```javascript
// src/api/client.js
const API_BASE_URL = import.meta.env.VITE_API_URL || '/api';

class ApiClient {
    constructor(baseUrl) {
        this.baseUrl = baseUrl;
    }
    
    async request(endpoint, options = {}) {
        const url = `${this.baseUrl}${endpoint}`;
        
        const response = await fetch(url, {
            headers: {
                'Content-Type': 'application/json',
                ...options.headers
            },
            credentials: 'include',
            ...options
        });
        
        const data = await response.json();
        
        if (!response.ok) {
            throw new ApiError(response.status, data);
        }
        
        return data;
    }
    
    get(endpoint, params = {}) {
        const queryString = new URLSearchParams(params).toString();
        const url = queryString ? `${endpoint}?${queryString}` : endpoint;
        return this.request(url, { method: 'GET' });
    }
    
    post(endpoint, data) {
        return this.request(endpoint, {
            method: 'POST',
            body: JSON.stringify(data)
        });
    }
    
    put(endpoint, data) {
        return this.request(endpoint, {
            method: 'PUT',
            body: JSON.stringify(data)
        });
    }
    
    delete(endpoint) {
        return this.request(endpoint, { method: 'DELETE' });
    }
}

class ApiError extends Error {
    constructor(status, data) {
        super(data.error?.message || 'API 请求失败');
        this.status = status;
        this.code = data.error?.code;
        this.details = data.error?.details;
    }
}

export const apiClient = new ApiClient(API_BASE_URL);
```

```javascript
// src/utils/cache.js
class DataCache {
    constructor(ttl = 5 * 60 * 1000) {
        this.cache = new Map();
        this.ttl = ttl;
    }
    
    set(key, data) {
        this.cache.set(key, {
            data,
            timestamp: Date.now()
        });
    }
    
    get(key) {
        const item = this.cache.get(key);
        if (!item) return null;
        
        if (Date.now() - item.timestamp > this.ttl) {
            this.cache.delete(key);
            return null;
        }
        
        return item.data;
    }
    
    invalidate(pattern) {
        for (const key of this.cache.keys()) {
            if (key.includes(pattern)) {
                this.cache.delete(key);
            }
        }
    }
    
    clear() {
        this.cache.clear();
    }
}

export const dataCache = new DataCache();

// 在 API 层使用
export const productService = {
    async getList(params = {}) {
        const cacheKey = `products:${JSON.stringify(params)}`;
        const cached = dataCache.get(cacheKey);
        
        if (cached) {
            return cached;
        }
        
        const response = await apiClient.get('/products', params);
        dataCache.set(cacheKey, response);
        return response;
    }
};
```

```javascript
// src/utils/errorHandler.js
export const errorHandler = {
    handleApiError(error) {
        console.error('API Error:', error);
        
        // 根据错误类型返回用户友好的消息
        if (error instanceof ApiError) {
            switch (error.code) {
                case 'NOT_FOUND':
                    return '请求的资源不存在';
                case 'VALIDATION_ERROR':
                    return '数据验证失败，请检查输入';
                case 'UNAUTHORIZED':
                    return '请先登录';
                case 'FORBIDDEN':
                    return '没有权限执行此操作';
                default:
                    return error.message || '请求失败，请稍后重试';
            }
        }
        
        if (error.name === 'NetworkError') {
            return '网络连接失败，请检查网络';
        }
        
        return '发生未知错误，请稍后重试';
    },
    
    async withErrorHandling(fn, fallbackValue = null) {
        try {
            return await fn();
        } catch (error) {
            console.error('操作失败:', error);
            return fallbackValue;
        }
    }
};
```
